# Data quality: human_v2 and scripted n40

Generated by `python tools/data_quality_report.py` (read-only on data and runs). Definitions are in the tool's docstring; the CSVs in this folder carry every number at full precision.

Sets: **human_v2 train** (40) and **val** (10) = `data/processed/splits_human_v2.json`, files in `data/processed/episodes_human_v2` (smoothed walking labels; states checked identical to the raw `recordings/demonstrations` files); **scripted n40 train** (40) = `splits_scripted_v3_n40.json`, files in `recordings/scripted_v3`. Lengths are 25 Hz ticks (0.04 s).

One definition for all three label sets: ON = |v| >= 0.1 (the smallest key value is 0.2). A pattern change = a tick whose sign pattern (vx, vy, wz at the threshold) differs from the previous tick; an on-run = consecutive ticks with one non-idle pattern. Forward + backward + strafe + turn can exceed 100 - idle: a tick can carry two commands. The per-episode columns do not depend on the scope and repeat on both rows.
